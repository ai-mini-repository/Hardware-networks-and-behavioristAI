# How Data travels Quality Check
## So in this file I am going to check and verify all information about how data travels and etc
### 1) "When you enter a website address, the browser uses DNS to find the server's IP address, establishes a connection, and requests web data, which travels through local network hardware (like routers and switches) and internet service providers in formatted data packets."
Quote from MDN Web Docs:
"When you type a web address into your browser... the browser goes to the DNS server, and finds the real address of the server that the website lives on... then the browser sends an HTTP request message to the server, asking it to send a copy of the website to the client... if the server approves the request, the server sends the client a '200 OK' message... and then begins sending the website's files to the browser as a series of small chunks called data packets."

this was written in our files this website clarifies our information: https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works.
### 2) "DNS (Domain Name System) translates human-readable domain names into IP addresses so devices can locate servers on the network without downloading the web page itself."
Quote from Cloudflare:
"The Domain Name System (DNS) is the phonebook of the Internet. Humans access information online through domain names, like nytimes.com or espn.com. Web browsers interact through Internet Protocol (IP) addresses. DNS translates domain names to IP addresses so browsers can load Internet resources."

the information above is verified in this website: https://www.cloudflare.com/learning/dns/what-is-dns/
### 3) "HTTPS protects data in transit between the browser and the website using TLS encryption and authentication."
Quote from Cloudflare:
"HTTPS stands for Hypertext Transfer Protocol Secure... HTTPS uses an encryption protocol to encrypt communications. The protocol is called Transport Layer Security (TLS)... HTTPS prevents sites from having their information broadcast in a way that's easily viewed by anyone snooping on the network."

link for the website and there is more information about it: https://www.cloudflare.com/learning/ssl/what-is-https/

### 4) "Data travels across networks in formatted units called packets, which are forwarded by routers between local networks (like Wi-Fi access points or switches) and internet service providers."
Quote from Cloudflare:
"Data sent over the Internet is broken down into smaller pieces called packets... Routers are networking devices that forward data packets between computer networks. Routers read the destination IP address of each packet to determine where to send it next."

link for the website: https://www.cloudflare.com/learning/network-layer/how-does-the-internet-work/

### 5) "While the network interface transfers data over Wi-Fi or Ethernet, the CPU executes operating system and browser instructions, and RAM temporarily holds active programs and data."

Quote from MDN Web Docs:
"Computers connected to the web are called clients and servers... Clients are the typical web-user's internet-connected devices (for example, your computer connected to your Wi-Fi, or your phone connected to your mobile network) and web-accessing software available on those devices (usually a web browser like Firefox or Chrome)."

verification link: https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Web_standards/How_the_web_works.
